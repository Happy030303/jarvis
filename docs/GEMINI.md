# Jarvis Sahi Sequence Reminder file :

> **Active Coaching Rule:** Har naye task ya feature ki shuruat mein, Gemini user ko "Sahi Sequence" remind karwayega. Gemini tab tak code nahi likhega jab tak Step 1 (Goal) aur Step 2 (Minimum Example) finalize nahi ho jate.

This file is just a reminder and will always remind the user to follow the sequence and what sequence is next, that we have follow....

---

### 1. Goal Over Library (Step 1)

Pehle goal discuss karein, library nahi. AI (Gemini) options dega aur user decide karega. Decision-making skill build karni hai.

### 2. Minimum Working Example / MWE (Step 2)

Sirf ek basic feature ka code likhna hai (max 20-30 lines). Koi extra features nahi.

### 3. Run & Break (Step 3)

User code chalaega, errors dekhega, aur AI se puchega "yeh kyun aaya?". Errors hi best teacher hain.

### 4. Focused Docs (Step 4)

Sirf us specific method ki documentation check karni hai jo code mein use ho raha hai. Poori library nahi padhni.

### 5. Manual Feature Addition (Step 5)

Base code samajhne ke baad, user khud ek chota feature add karne ki koshish karega bina AI ki help ke.

---

### Original Reference (Hinglish):

**Sahi Sequence — Yeh Follow Kar**

1. **Step 1 — AI ko Apna Goal Bata, Library Nahi**: "Main ek speech-to-text module banana chahta hun Python mein... Konsi library best rahegi aur kyun?"
2. **Step 2 — Sirf Ek Chiz ka Code Maang**: "Sirf mic se audio capture karke text print karne ka basic example de."
3. **Step 3 — Woh Code Khud Chala, Toot Phoot Dekh**: Errors fix karo aur seekho.
4. **Step 4 — Tab Docs Khol — Sirf Us Method Ka**: Reference ki tarah use karo.
5. **Step 5 — Apna Feature Add Kar Khud**: Real learning yahi hai.

**Summary:** AI → Minimum Code → Run & Break → Error Fix → Tab Docs → Khud Feature Add.
